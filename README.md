## 🎯 Project Overview

The **Student Management System** is a simple console-based application developed using Python. It helps manage student records through essential operations such as adding, viewing, searching, updating, and deleting student information.

The application uses JSON-based data storage and a simple menu-driven interface to manage student records.

---

## ✨ Key Features

| Feature | Description |
|:---|:---|
| ➕ Add Student | Add new student records |
| 👨‍🎓 View Students | Display student records |
| 🔍 Search Student | Search for a student |
| ✏️ Update Student | Modify existing student details |
| 🗑️ Delete Student | Remove student records |
| 💾 JSON Storage | Store student data using JSON |
| 📋 Menu Interface | Simple menu-driven interface |

## ⚙️ Installation & Setup

### 1. Prerequisites

- Python 3 installed on your computer.
- Visual Studio Code or another code editor.
- Git (optional).

### 2. Clone the Repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 3. Open the Project Folder

```bash
cd Student-Management-System
```

### 4. Verify Python Installation

```bash
python --version
```

### 5. Run the Application

```bash
python student_management.py
```

**Windows alternative:**

```bash
py student_management.py
```

The main objective of this project is to develop a simple and user-friendly student record management application using Python.
